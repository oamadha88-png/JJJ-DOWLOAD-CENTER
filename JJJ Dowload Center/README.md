# JJJ Dowload Center

Website katalog download aplikasi multi-platform untuk Jujoys Group.

## Menjalankan

Buka `index.html` langsung di browser, atau gunakan Live Server di VS Code.

## Yang perlu diganti sebelum online

- Ganti `download: '#'` di `script.js` dengan URL file APK, EXE, atau DMG yang sebenarnya.
- Software berlisensi seperti Adobe Photoshop harus diarahkan ke situs resmi Adobe/Creative Cloud, bukan di-host atau dibagikan ulang tanpa izin.
- Tambahkan logo dan screenshot aplikasi bila sudah tersedia.
- Upload folder ini ke GitHub Pages, Netlify, atau Vercel.
